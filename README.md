# maikrieffenstahl.com

Portfolio of Maik-Sebastian Rieffenstahl, UX Design Manager and Digital Solutions Designer. Static HTML, CSS and a little vanilla JavaScript. No framework, no build step.

## Structure

| Path | What it is |
|---|---|
| `index.html` | Home page |
| `how-i-work.html` | Long version of How I work |
| `resume.html` | Resume; the Download PDF button prints this page with the print stylesheet |
| `work/garantiemax.html`, `work/raptive.html`, `work/spandau-04.html` | Case studies, currently "coming soon" pages |
| `styles.css`, `script.js` | Shared styles and behaviour (copy email, print, year) |
| `assets/` | Images |
| `vercel.json` | Clean URLs and redirects from old paths |

## Deploy

Vercel, framework preset "Other", root directory `/`, no build command, no output directory. Every push to `main` deploys.

Status: work in progress, September 2026.
